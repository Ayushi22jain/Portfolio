# Personal Portfolio Website
Welcome to my personal portfolio repository! This project is a custom-built website designed to showcase my work, skills, and creative journey as a developer and data enthusiast.

## ✨ Features
Interactive UI: Smooth transitions and engaging user interface.

Modern Animations: Integrated GSAP (GreenSock Animation Platform) for high-performance, complex animations.

Responsive Design: Optimized for various screen sizes using clean CSS and HTML.

Creative Styling: Custom aesthetics that reflect my professional brand.

## 🛠️ Tech Stack
HTML5: Structure and content.

CSS3: Custom styling, layout, and visual effects.

JavaScript: Core logic for interactivity.

GSAP: Used for advanced motion graphics and scroll-triggered animations.

## 📂 Project Structure
Project2.html: The main entry point of the portfolio.

portfolio.css: Contains all custom styles and layout configurations.

a22.jpg: Assets used for visual representation.
